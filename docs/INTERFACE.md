# 枕头堡 P1 走位色块表现层

## 集成与文件

只在Canvas挂 `Boot.ts`，不要同时挂其父类 `PillowFort.ts`。Cocos 3.8.8使用750×1334、FIXED_WIDTH和正交2D Camera。入口只读取 `resources/data/levels.json`，没有读取或生成正式美术。

- `GameController.ts`：存档、波推进、奖励、拖动/长按、前后台、开发调试和CSV。
- `GameView.ts`：真实core状态转换为分层绘制命令与点击区域。
- `Draw.ts` / `Theme.ts`：绘制契约、颜色和表现常量。
- `PillowFort.ts`：Cocos Graphics与Label池、触摸/鼠标/前后台适配，仍待真实引擎验证。
- `CanvasPreview.ts`：共享代码的引擎外浏览器预览，非正式平台包。

## 当前操作

- 玩偶面板：卡片拖进窝上场；战场上拖动已上场玩偶改变守点；拖出窝下场。设施同样操作。名额满时拒绝新增，不替换其他玩偶。
- 拖动超过阈值后面板收起，露出放置区域。不动辅助随拖动实时移动；取消会恢复原守点。其他玩偶松手提交新home，按各自速度搬过去。
- 点选玩偶：菱形守点、虚线活动范围、大/冲的地面边界、细圈射程、绿色光环。长按看最近命中分解；长按后不误拖，松手不误触。
- 升级按钮长按连续购买，移出/取消/切后台即停止。面板打开时战斗继续；弹窗按自身规则拦截输入。
- 手电默认自动，按住按钮切手动，拖向梦境瞄准；设置可切回自动。49波可挑战首领，撤退/立即再试不虚增冷却。
- 750×1624比1334只增加表现纵向偏移290，core坐标和轨迹不变；输入做相反变换。

玩偶高120像素，背面压暗、侧面压窄。不动/小范围只用正面并按左右翻转。弹道从释放时的占位发射点出，已发射后转身/下场不会拉动起点；数字与实际命中同步。绵绵先绘制/登记命中区，前线玩偶优先被选中。

## 存档与生命周期

保留 `zhentou.save.v1` 键，内容交由core自动迁为v2；启动后立即写回，因此升级前手工备份旧档。奖励在早安卡出现时已结算并保存，“收下”只关闭卡片。取消、失去捕获/焦点、切后台结束当前手势；已提交但尚未进入下一tick的home也会保存。恢复后的第一帧不重复追赶离线时间。

守点输入通过固定逻辑帧的 `step({homes})`，并将 `battle.save` 中的home同步回主Save。上/下场和设施通过 `place/placeDevice` 后同步战斗。完整会话录像导入不在本轮范围。

## 开发功能与验证

- Cocos使用 `DEV`，发布构建隐藏调试入口。
- Canvas只在 `?debug=1` 暴露调试操作与 `window.pillowfort`；F3切范围/目标/状态/弹道数覆盖层。
- CSV增加首次挨打距墙秒均值。浏览器下载文件；微信开发环境写用户数据目录供开发者工具提取，不自动分享。
- 当前UI自动测试41项，独立控制器/绘制复核10组；具体总结果见 `VALIDATION.md`。
- 4组GameView离屏预览见 `screenshots/p1-walk/`。调试叠加图信息密集，不代表发布界面；这些图不是浏览器/引擎/真机截图。

仍待本地确认：Cocos类型与场景、触屏事件顺序、真机安全区/胶囊、H5和微信构建、帧率/内存与字体。纯色块未覆盖ArtGen/Rig、正式图自动替换、缺图/缓存更新链。效果池和上限不能替代性能测量。
