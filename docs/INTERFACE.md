# 枕头堡 P1：色块表现层

## 集成

- 将本目录 `*.ts` 放入 `assets/scripts/ui/`；纯逻辑放在同级 `core/`。
- `PillowFort.ts` 是 Cocos Creator 3.8.8 入口组件，挂到 750×1334 Canvas。也可由 `Boot.ts` 继承它。
- 入口读取 `assets/resources/data/levels.json`，不读取或生成任何旧版美术。
- 场景需要 Canvas 与正交 2D Camera，使用 `ResolutionPolicy.FIXED_WIDTH`。
- 所有角色、敌人、羊、弹道、设施、背景都以矩形色块表现；手电使用简单半透明三角形。渲染不依赖图片、音效或第三方运行库。

## 文件

- `GameController.ts`：固定逻辑步进、存档、离线收取、波间推进、五页签动作、拖动/长按、开发调试、CSV。
- `GameView.ts`：按 `nest` 原始坐标生成绘制指令和点击区域。
- `Draw.ts` / `Theme.ts`：绘制接口、颜色和表现常量。
- `PillowFort.ts`：Cocos Graphics + 分层 Label 对象池、输入和前后台适配。
- `CanvasPreview.ts`：独立 Canvas 诊断入口，复用同一 Controller、View 和 core；不是 Cocos 引擎构建产物。
- `tests/ui.test.ts`：22项行为与布局自动化测试。

## 操作

下方五页签打开面板；面板打开时战斗继续。点场上位置可选玩偶；若想点两个位置交换，先选第一个，再点面板中的“点两个位置互换”，随后点第二个位置。首次点“帮”会显示无遮挡的邻位连线，再点同一位置才打开换阵；长按场上的玩偶查看最近真实命中的倍率快照（没有命中过则明确显示当前预估）。倍率保留原始精度，内容过长时分页。升级按钮长按可连续升级，拖离或取消会立即停止。

手电默认自动，按住手电按钮即切为手动，拖向梦境瞄准。设置里可以切回自动。首领按钮在49波出现，挑战不收费，战斗中可点“先回去”。第三个梦通关后保持49波挂机，显示“下一个梦还在路上”，不会进入未开放区域。

首次进入先显示开场；离开60秒以上显示早安卡。奖励在出卡时原子写入存档，点击“收下”只关闭卡片，重复点击或重开不会重复发放。切后台保存并取消触摸和长按，回来重新接受新触摸；忽略第一个陈旧的绘制时间差，避免离线奖励与旧帧追赶重复计算。立即挑战/撤退不计算虚构的波间时间，只有真正的自动波间休息累加充能和冷却。

## 开发入口

- Cocos 使用 `cc/env` 的 `DEV`，发布构建不显示调试入口。
- Canvas 诊断预览仅在 URL 带 `?debug=1` 时显示开发功能，并暴露 `window.pillowfort` 供自动化QA。
- 开发面板三页：跳波/资源/等级、倍速/离线/调试显示、CSV/存档重置。
- 浏览器 CSV 直接下载。微信开发环境写入 `USER_DATA_PATH/zhentou-waves.csv`，由开发工具提取；不调用分享功能。

## 验证范围

已运行：严格 TypeScript 检查（纯逻辑、Controller、View、Canvas）；UI控制器22项自动化测试。测试覆盖长短屏玩法不变、布局位置、手动瞄准反变换、实时换位、长按/取消、弹窗触摸阻挡、即时奖励、离线幂等、发布版调试隔离、按钮边界、CSV、终章挂机、切后台长按取消、无遮挡辅助连线、真实命中倍率快照、倍率分页，以及重复挑战/撤退不增加充能。

仍需真实环境验证：Cocos 3.8.8 引擎类型检查与场景运行，iOS/安卓安全区和微信胶囊，微信/TapTap正式构建、真机帧率/内存、字体观感。没有使用引擎声明桩来声称通过。独立 Canvas 验证不代表这些项目通过。

本轮按用户要求全部使用色块，不交接旧图、不做 ArtGen 或美术生成/缓存验收。动画是矩形位置变化、撞击抖动、弹道与回家小羊。统一效果池上限150，同屏伤害数字6、小羊12、敌人可视对象40；超出敌人数合并显示但逻辑继续。性能目标必须在真机测量，不以代码上限当作已达标。
