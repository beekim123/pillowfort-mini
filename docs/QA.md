# P1 独立验收计划

本计划不预填“通过”。请在对应环境实际执行后记录结果、日期、机型、版本和证据路径。Node 纯逻辑、引擎外 Canvas、Cocos 预览、H5 发布包、微信开发者工具、手机各是独立阶段。

## 0. 验证顺序

1. `npm ci` → `npm test` → `npm run typecheck` → `npm run check:spec` → `npm run check:source`。
2. `npm run build:preview`，只用于共享规则 / 绘制命令与交互检查。
3. Cocos 3.8.8 导入场景，`npm run typecheck:cocos`，浏览器预览。
4. H5 与微信真实引擎构建、ZIP 完整性、平台工具运行。
5. iPhone 与中低端 Android 各运行：测 FPS、峰值内存、前后台、触摸与安全区。
6. 正常新存档完整游玩与 20 分钟一波一行 CSV。逻辑仿真不能替代真实 20 分钟游玩。

## 2. 交互回归（两种高度都跑）

- 全新存档打开：开场两句话可关闭，升级引导不会挡住后续按钮。
- 玩偶、枕头堡、白天、纸箱、设置五页签：打开 / 切换 / 关闭各三次，战斗持续推进，不叠加弹层或点击处理器。
- 连点升级、资源恰好够 / 不够、长按升级后移出、触摸取消、后台切换时松手：不发生粘住的重复购买。
- 点格子再选玩偶，点两格交换；锁格不可选；同一玩偶不重复上阵；正在冲时换位不遗留空节点。
- 点辅助，连线只到相邻有效格；切换选择和关闭面板后线正确消失。
- 手电自动转手动，按住拖动、移出画布、抬起、取消、后台恢复；不得一直照或重复消耗。
- 长按玩偶查看分解：乘数一致；抬手/关闭后不误触换位。
- 战斗进行时反复切页、升级、换阵、改变屏幕尺寸；触摸热区跟画面一致。
- 早安卡只领一次；快速双击领取、领取后重启不重复发羊/糖。
- 调试清档必须有明确按钮；连续打开调试再关闭不留下挡触摸的透明层。
- 750×1334、750×1624，普通和最长文案：字号、换行、边距、胶囊留空、安全区、弹层不遮挡关闭键。
- 截图至少包括：开局、战斗、挡/挤倒、冲、辅助连线、手电、精英、49波、大噩梦3种、失败、早安卡、各面板、分解、破万、调试。

## 3. 状态转换和重复操作

- 前后台切换10次。切后台存档；恢复时离线按真实时差结算，不推进梦或打大噩梦。
- 30秒、1h、8h、20h离开，手机时间回拨；检查离线、纸箱、每天小事分别按规则走。
- 大噩梦失败反复重试：不扣额外资源，伤害比例记录准确；成功奖励只发一次。
- 第2区大噩梦胜利之后继续打开、重启：仍停在P1，“下一个梦还在路上”。
- 缺少存档、损坏JSON、存储写失败：能提示或安全恢复，不静默刷无限离线奖励。
