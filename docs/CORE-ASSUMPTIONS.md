# 走位版规则冲突与暂定选择

本轮使用附件原始JSON v2，不改写正本来掩盖冲突。正文中未结构化的参数集中在 `assets/scripts/core/rules.ts`。以下是本轮实现口径，不代表设计方已确认或平衡已通过。

## 新版优先关系

- 速度按 `nest.spawn.speed=56`，不沿用正文残留65。
- 每通一大噩梦等级软上限增量按68，三次为304，不沿用+70/310。
- 存档写version2。旧版12格仅用于迁移，不再驱动玩法；homes超过6只是备用默认点。
- `aoe`、dash的bossMul/waveMul、flash的manualBoss/autoBoss是核算系数，不额外乘进真实伤害。
- 正本仍含“同排”等旧描述；游戏说明改用距离光环。规格中正式美术、ArtGen/Rig接入要求不属于本次纯色块范围。

## 走位与命中

1. 圆心(375,1170)、墙半径360；守点受半径332、横界40..710、bottom1196共同约束。小/中活动半径45/140，大/冲按整块地。
2. 搬动home不瞬移可走玩偶；先以自身速度到新home，再恢复选敌/溜达。途中可暂在新leash外。冲刺回程使用最新home。不动辅助即时到守点。
3. 玩偶间距目标为0.6×120=72；不动者和挤倒者不可推动，冲刺者不参与普通避让。两个不动者被放在同一点时，“不动”优先，不能保证72间距；地形/leash限制下也不承诺全局最优排列。
4. 挡的可认领墙点使用30px内缩、50px可达容差；迎敌内侧44、接触58、最多2只按新版参数。空闲耐力恢复暂为0.8/秒。挤倒释放怪物，让它继续走/挤墙，不立即判漏。
5. 打的接近目标点采用reach×0.85，随后受活动范围/地面限制；正常走动不新开普通攻击。避让产生的校正位移不等于寻路速度。
6. 冲出560、返回300、三击间隔0.25秒；接触偏移暂为目标下方34px，冲途接触半径24px。目标消失改最近活体，实际走到后命中，不再固定一秒传送。
7. 攻击/技能在决定出手时快照攻击和光环；目标冻/光/壳等在命中时读取。已释放弹道在发射者下场后仍按快照结算；目标已死的单体飞至最后点散去，范围攻击在最后点爆炸。
8. 老袜普通按具体技能表作单体，主动技能在190px范围附三层臭。正文4.4对aoe的泛化说法与此冲突，本轮优先具体技能表；普通范围回归已单独覆盖。
9. “首次挨打距墙还有几秒”取每个敌人首次实际伤害>0时的剩余径向墙距÷其基础移动速度，再按受击敌人求均值。冻结/减速不改分母，零速度记0，0伤手电不触发；这是可比较的诊断指标，不是实际未来存活时间。
10. 无完整会话录像器。守点通过固定tick输入并记录；要复现经济、上/下场和设施变化，还需同初始档与同序外部操作。跨进程恢复不保存波内所有弹道/计时器。

## 沿用且仍需确认的规则

11. 暴击倍率2但没有概率，默认概率0，不擅设5%等概率。
12. 技能、绵绵、手电跨波保留运行时carry；只有真实波间时间计冷却。立即挑战/撤退默认0秒。耐力/挤倒每波重置，新上场玩偶重新计冷却。
13. 击杀羊即时入账，波末只补差。小怪奖励优先开发文档4.11：最大血×0.01+3，不把固定+3再按分裂/成群比例缩减；notebook已有0.4血量系数，不重复相乘。
14. 暖DOT以命中伤害为基数，刷新取较大值，不在每个DOT tick重复乘目标易伤；臭记录各层基数。壳只挡直接命中，不挡DOT；三次凉命中按滑动2秒窗口，触发后清空计数。
15. 呼呼/老袜/嘎嘎主动先做标准属性命中，再附增强烘/三臭/推回。方方×5，咔咔六次链，阿冰技能全场冻；辅助技能仅buff，软软生成分身。
16. 分身不挡首领，最多挡一只，耗尽或6秒到期释放；原目标消失后只在24px内接新怪，不远程冻结。分身耐力按阻挡秒数消耗，不额外乘精英倍率。
17. 手电扇角由顶端全宽225px计算；自动偏好距墙≤300的最大覆盖方向。独立眩晕3秒，光中1.5易伤，不额外算凉冻1.2。DPS基数取最近5秒实扣伤害/5，包括此前光束伤害。
18. 离线羊/糖最多8小时，箱与每日按全部真实时间。每日续费只用结算前已有羊，不预支本次离线收入。无农场时羊/估算击杀0，但整小时糖照算；缺历史波时长不捏造击杀数。
19. 失败退2，连续三次干净守住才恢复推进；计数中有漏重新记3。P1第三首领通后停第2区49波，保留completed，不进入后续阶段。
20. 金额double、上限1e300、倍率连乘；超中文单位时用4位向下截断科学记数法。缺外部大数字5.5完整表，不声称全表验证。

完整历史问题讨论在 `review/`，其中旧站位结论已被本文和v2规格替代。正式图、公共build-kit、Cocos双平台、触屏和50FPS仍待各自验证。
