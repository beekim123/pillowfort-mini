# 源码交接

## 当前交付

仓库候选目录是完整、独立的Cocos Creator 3.8.8源码骨架与纯色块玩法实现。新增/修复的最终文件统一在本目录，不依赖开发时的其他共享路径。`npm ci` 后可运行共享测试和引擎外Canvas预览。

目标仓库：`https://github.com/beekim123/pillowfort-mini.git`。已只读核验为公开空仓库（默认main），独立审查与最终推送指示均已收到。交接提交只写本仓库main，不强推、不覆盖未知远端提交，推送前再次核验远端状态。推送结果以远端提交及任务交付消息为准。

## 已合并

- 完整core、22项UI行为测试、独立核心/界面回归、平台空能力接口。
- 需求矩阵、实现规则缺口、最终验收状态、构建与本地验证步骤。
- 源码检查、规格SHA、测试/仿真/工具验证日志。所有日志应与最后一次源码修改后重跑的结果一致。
- 独立QA证据只证明共享绘制/事件模拟，不证明Cocos或手机运行。

## 提交范围

包含源码、原始规格数据/文档、测试、锁文件、工具、少量验证证据。不包含node_modules、Cocos library/temp/local、preview生成缓存、build平台产物、账号凭证、私有IDE配置、旧美术代码或图片。
