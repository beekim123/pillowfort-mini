## 证据方法与边界

这些图是项目实际 GameView 输出的 DrawCommand 经独立 Pillow 离屏绘制的结果，使用 Noto Sans CJK SC 系统字体。不是浏览器、Cocos、微信或手机截图。字体栅格和基线可能与实际引擎不同。

交互检查在 Node 中实例化真实 GameController/GameView，通过实际命中区域调用 pointerDown、pointerMove、pointerUp、pointerCancel，并推进真实战斗逻辑。它验证共享界面控制器，不验证浏览器或引擎输入适配层。

本轮未取得真实浏览器运行证据。Cocos和真机验证尚未执行，因此本目录仅提供控制器与离屏绘制证据。
