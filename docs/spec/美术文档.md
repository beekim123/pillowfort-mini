## 1 画风：水粉颗粒（夜色）· 梦里

底子是画风库的 `grainy-gouache`（`styles/grainy-gouache/`：README、`style.config.mjs`、`gouache.mjs` 笔法、`out/` 三件试画）。**笔法照它，交付改成 Canvas2D 代码**。

一句话：**夜里的梦，柔和的水粉色块 + 往边缘和暗处聚的细颗粒，没有描边；玩偶是暖的、亮的、毛茸茸的，噩梦是深色的、软的、只露一双发亮的眼睛，羊是白的。**

### 1.1 要遵守的画法（照原画风）

- **不描边**：形体之间靠明暗差和颗粒边分开。
- 每个大形体一个径向渐变，4 档（受光 → 中间 → 暗 → 边缘），**光从左上来**（光点约 0.42, 0.30）。
- 颗粒：只在形体的暗面和边缘，量和颜色照 **1.5 节**（第 1 批太多、显脏）；脸上的细节（嘴、高光）画在颗粒外面保持干净。**颗粒用画笔库预先生成的颗粒纹理铺**（`clip` + `drawImage`），不要一颗颗画（方案 3.3 第 4 条）。
- 背光侧一道柔和的月光（`rim`），把角色从深色底上托出来。
- 眼睛（玩偶）：奶油色圈 + 大黑瞳 + 一颗四角星高光 + 一个小圆点。
- 脚下一块柔和的深色椭圆影（`pool`）。

### 1.2 这一款要改的

- **噩梦的眼睛是另一种**：没有奶油圈，是一对**发光的眼睛**（暖白 / 淡黄，外面一圈柔光），瞳孔是竖的小黑点或一道缝；圆滚滚、有点委屈、**吓人但不恐怖**（没有牙、没有血、没有尖爪）。
- **噩梦是深色的，梦的背景也偏暗**——这是最大的风险。规矩：背景是**中间调、偏灰、低饱和**；噩梦比背景**更暗**，靠**淡紫色的月光边 + 发光的眼睛**认出来；玩偶和羊比背景**亮**、暖。**转灰度检查：玩偶 / 羊最亮，背景中间，噩梦最暗**，三层分得开。
- 玩偶是**旧的毛绒玩具**：毛有点起球、缝线若隐若现、颜色温暖但不艳。**不要泰迪熊**（竞品的主角就是泰迪熊）；不要纽扣眼（《纽扣剧团》用过）。
- 原画风里的“杂音斑”这里不用。

### 1.3 色板（起点，美术可以调，调了写进交付说明）

`palette.json` 从 `grainy-gouache/style.config.mjs` 起步（`grain`、`rim`、`cream`、`blush`、`faceInk`、`pool`、各色族 ramp 照用），再加：

| 色族 | 用在 | 建议 |
|---|---|---|
| `night` | 梦的背景（中间调，偏灰） | `#3A3F6B` → `#2B2F55` → `#1F2242` → `#171A33` |
| `fog` | 梦的上边（噩梦从这里出来的那片雾） | `#2A2448` → `#1A1630` |
| `nightmare` | 噩梦的身体（比背景暗） | `#2A2850` → `#1C1A3A` → `#120F26` → `#0C0A1C` |
| `nmRim` | 噩梦的月光边 | `#B9A8FF`（半透明） |
| `nmEye` | 噩梦发光的眼睛 | `#FFF3C4` 中心、`#FFD86B` 外圈 |
| `wool` | 绵绵、羊的毛 | `#FFFDF6` → `#F2EEE4` → `#D6D2DE` → `#ABA7BE`（暗面偏蓝灰，不发黄） |
| 五种属性 | 打中特效、状态 | 枕头 `#FFF1D6`、暖 `#FF9A45` / `#FFD35E`、凉 `#8FE3FF`、静电 `#FFF27A` + `#C9A8FF`、臭 `#A6C35A` |

玩偶的身体用原有的 `moss`（呼呼）、`gold`、`orange`、`coral`、`teal`、`berry`、`violet` 等 ramp。

### 1.4 要的样子：活的（2026-11-06 加）

用户看了第 1 批，想要的样子最接近**你上次在画风库做的实时版**（`style-lab/index.html` → 官方做法 → 墨线手绘那 4 个；返修包的 `参考/` 里有拷贝和说明，质感参考是同目录的水粉颗粒试画）：**笔触多、边在沸腾、动起来很生动**——只是画法换成本节的水粉颗粒。具体：

- **形体是一笔笔叠出来的，不是一个渐变填满的光滑矢量形**：大形体先铺一层底色，再沿形体走向叠几十道半透明的水粉短笔（有干笔的飞白、边不齐），暗处多叠、受光处少叠；轮廓边是笔触的边，不是一条光滑的曲线。
- 颗粒是**纸面的质感，不是脏点**：量照 1.5 节（2026-11-06 改，原来写的“1× 下看得见”推得太重了）。
- **沸腾要看得出来**：3 张变体之间，笔触的位置、轮廓边的起伏、颗粒都在变（造型不变），轮换起来像手绘动画那样“活”着，不是只有颗粒在闪。
- **预算是让你用的**：L1 每个部件、L2 每帧上限 3000 次画图调用；常见在几百到一千多次。第 1 批每个部件 26 次左右，说明笔触远远不够。
- **动作有手绘动画的弹性**：预备、挤压拉伸、跟随（耳朵、尾巴、丝带晚一点到），`idle` 里也要有小的次要动作，不只是整体上下浮。
- 造型照第 3 节的描述从这个世界里长出来，不套常见模板（例如一圈波浪下摆的“床单鬼 / 吃豆人幽灵”；恐龙看起来像乌龟）。

### 1.5 颗粒的量（2026-11-06 加：第 1 批返修版颗粒太多，看着脏）

返修版的问题（看了画笔库）：颗粒贴图每 96×96 撒 320 个点（约四分之一面积有点），每个形体再撒 18–68 个深色斑点，两层叠着；颗粒统一用深蓝灰，白羊毛、脸上也撒，像脏点；背景又铺了一层全屏颗粒。改成：

1. **只在暗面和边缘**：颗粒只出现在形体背光的那一半和边上一圈（宽不超过形体短边的 12%）；受光面、脸（眼睛、嘴、腮红一圈）、高光、白毛的受光面**一颗都不要**。
2. **同色系深一档**：颗粒的颜色 = 底下那块颜色在自己色族里深一档（白毛用 `wool` 的第 3 档再淡一点）；**不用统一的 `grain` 深蓝灰，不撒亮点**。
3. **对比和面积**：转灰度看，颗粒和旁边底色的亮度差不超过 6%；在暗面里点占的面积不超过十分之一；点的直径 0.8–1.6 设计像素。
4. **只铺一层**：颗粒贴图和斑点二选一，不叠。
5. **背景要干净**：噩梦走的那片地（屏幕 y 262–774）和窝里，颗粒几乎没有（面积 ≤ 3%）；颗粒只留给雾、两边的暗处。角色比背景“干净”，才从背景里跳出来。
6. **一个总旋钮**：画笔库导出 `setGrain(k)`（0–1，默认 1 = 上面这些上限），所有颗粒的透明度和数量都乘它，0 = 完全没有颗粒。我们在画风库里拖滑块定最后的值，以后调不用返工。
7. 沸腾不靠颗粒：3 张变体之间主要是**笔触边和轮廓**在变（1.4 节），颗粒少了照样要“活”。

## 2 怎么跑：级别和模块（细化方案第 2、3 节）

### 2.1 每个模块的样子

所有模块：ES module、只用 Canvas2D、坐标写**设计像素**（屏幕宽 750）、确定性（同一个 `seed` + `boil` 永远同一张图）。生成器传 `opt = { seed, boil, scale, variant }`，模块自己 `ctx.scale(opt.scale, opt.scale)`。

```js
// L1 部件 + rig（玩偶、绵绵、糯糯、设施、手电筒）
// 2026-11-06：会走的玩偶（活动范围 中 / 大 / 冲）画三套朝向；不走的（不动 / 小）、绵绵、糯糯、设施只有 front
export default {
  key: 'toy_huhu', level: 'L1', size: [140, 150], anchor: [70, 138], boil: 3,
  facings: ['front', 'back', 'side'],          // front 正面（脸朝镜头）、back 背面（背朝镜头，看得到后脑勺）、side 侧面（画朝右，往左时游戏翻转）
  parts: {                                      // 每个朝向一张部件表，按绘制顺序（从后往前），坐标都是整张画布的设计像素
    front: [
      { id: 'shadow', parent: null, rect: [30, 128, 80, 18], pivot: [70, 138] },
      { id: 'body',   parent: null, rect: [28, 50, 86, 92],  pivot: [70, 138] },
      { id: 'blink',  parent: 'head', rect: [...], pivot: [...], hidden: true },
      // 不需要沸腾的小部件写 boil: false（只画一张）
    ],
    back: [...], side: [...],
  },
  drawPart(ctx, id, opt) { /* opt.facing 是哪一套；用整张画布的坐标画这一个部件；生成器负责裁到 rect */ },
  anims: {                                      // 每个朝向一组动作（哪个朝向要哪些动作见 3.2.1）
    front: { idle: { dur: 1800, loop: true, tracks: {/* 照 资源对接约定 4.2 */} }, walk: {...}, cheer: {...}, startled: {...} },
    back:  { idle: {...}, walk: {...}, attack: {...}, skill: {...} },
    side:  { idle: {...}, walk: {...}, attack: {...}, skill: {...} },
  },
  muzzle: { front: [70, 70], back: [70, 64], side: [112, 72] },   // 发射点：弹道从这里出来（整张画布的设计像素，每个朝向一个）
  release: { attack: 250, skill: 500 },                            // 出手帧：出手动作第几毫秒放出弹道（attack 的数 = art-manifest 的 release，和游戏对齐，别改）
};
// 只有一套朝向的老写法（parts 是数组、anims 不分朝向）也认，当作只有 front。

// L2 帧动画（噩梦、羊）
export default {
  key: 'nm_eyes', level: 'L2', size: [120, 120], anchor: [60, 108], boil: 1,
  variants: ['normal', 'elite'],               // 精英：生成器另画一套，尺寸 ×1.4
  anims: { walk: { frames: 8, fps: 10, loop: true }, hit: { frames: 4, fps: 12 }, burst: { frames: 8, fps: 14 } },
  drawFrame(ctx, anim, i, opt) { /* opt.variant = 'normal' | 'elite' */ },
};

// L3 笔刷 + 特效配方（打中、属性效果、光束）
export default {
  key: 'fx_warm', level: 'L3',
  brushes: { puff: { size: [48, 48], draw(ctx, opt) {} }, spark: { size: [16, 16], draw(ctx, opt) {} } },
  effects: {
    hit:  { brush: ['puff', 'spark'], count: [6, 10], life: [0.25, 0.45], speed: [60, 180], angle: [0, 360],
            scale: [0.6, 1, 0.2], alpha: [1, 0], tint: ['#FFD35E', '#FF9A45'], blend: 'add' },
    burn: { attach: 'target', loop: true, brush: ['puff'], rate: 8, life: [0.4, 0.7], speed: [10, 30], angle: [250, 290],
            scale: [0.4, 0.7, 0.1], alpha: [0.8, 0], tint: ['#FF9A45'] },
  },
};

// L3 弹道（每只玩偶一个：shot_<玩偶>）。kind 照 art-manifest（和游戏的 levels.json 一致），决定要画哪几样：
//   straight 直线：fly（朝右，游戏按方向转）+ 可选 trail + hit
//   lob 抛物线：fly（正着画，游戏让它边飞边转）+ hit
//   beam 柱子：beam（朝右的一段，左右接得上，游戏按两点距离拉伸 / 平铺）+ 可选 cap + hit
//   chain 电光：bolt（朝右的一段，同 beam）+ hit
//   melee 近身：只有 hit
//   帮的玩偶另画 aura：脚下一圈平放在地上的柔光（直径 = 2 × 光环半径，游戏按需要缩放）
export default {
  key: 'shot_huhu', level: 'L3', kind: 'straight',
  brushes: {
    fly: { size: [44, 32], frames: 3, draw(ctx, opt) { /* opt.frame = 0..frames-1，循环播；opt.boil 照常 */ } },
  },
  effects: {
    trail: { brush: ['...'], rate: 30, life: [0.2, 0.35], ... },   // 跟着飞的拖尾（字段同上面的配方）
    hit:   { brush: ['...'], count: [8, 12], ... },                 // 打中
  },
};

// bg（背景、枕头堡、栅栏，以后的界面件）
export default { key: 'bg_dream_0', level: 'bg', size: [750, 1624], draw(ctx, opt) {} };

// L0 实时（大噩梦，第 3 批才有）
export default { key: 'boss_closet', level: 'L0', size: [300, 300], anchor: [150, 280],
  init(opt) { return state; }, update(state, dt, events) {}, draw(ctx, state, opt) {} };
```

- 弹道怎么从玩偶飞到噩梦、飞多快、抛多高，是游戏定的（`levels.json` 的 `toys[].shot`）；美术只画“飞的样子”和“打中”，**不要在模块里画飞行轨迹**。
- **特效配方的字段**（开发照这个写一个简单的精灵粒子：对象池、合批）：`brush` 随机选一个；`count`（一次喷几个）或 `rate`（每秒几个，`loop` 时）；`life` 秒；`speed` 设计像素 / 秒；`angle` 度（0 = 右、90 = 下）；`scale` = [出生, 中间, 结束]；`alpha` = [出生, 结束]；`tint` 随机一个颜色乘上去；`blend` = `normal` / `add`；`attach: 'target'` 跟着目标走；可选 `gravity`（设计像素 / 秒²）、`spin`（度 / 秒）。不够用的写进交付说明，我们来加。
- **`boil`**：每个部件 / 每帧画几张颗粒沸腾变体（`opt.boil` = 0、1、2）。L1 在游戏里每秒轮换 6–8 次，相邻部件错开相位。L2 噩梦同屏很多，`boil: 1` 就够（帧动画本身在动）。**`opt.boil` 可以是任意整数**（实时模式会一直往上数），模块用它混进随机数，不要只认 0–2。
- 动作名照第 3 节。非循环动作播完要回到 `idle` 第一帧的姿势。

### 2.2 L1 的“实时模式”（展示场景用，美术不用另写）

早安卡、纸箱开出新玩偶、解锁卡上要一只大大的玩偶：生成器用同一个 L1 模块，按 2–3 倍放大，**每秒 6–8 次用新的 `boil` 现画部件**，部件照常跟 rig 动。所以 L1 模块放大到 3 倍也要好看（线宽、颗粒按设计像素定，方案 3.3 第 3 条）。

### 2.3 级别分配（P1 全部）

| 级别 | P1 用在 | 同屏 |
|---|---|---|
| L0 | 三个大噩梦（打它的时候） | 1 |
| L1 | 9 只玩偶（会走的 5 只三套朝向）、绵绵、糯糯、小夜灯、小风扇、手电筒、小枕头分身 | 上场 6 只 + 约 7 |
| L2 | 9 种噩梦（+ 精英）、羊（含棉花团） | 噩梦 ≤ 40、羊 ≤ 12 |
| L3 | 9 只玩偶的弹道（`shot_*`）、五种属性的打中和状态、壳、漏怪、手电筒光束、破单位 | 几十到几百个粒子 |
| bg | 3 个梦的背景、枕头堡（3 档）、栅栏、（第 4 批）界面件 | — |

## 3 P1 资源

尺寸是**设计像素**的画布（游戏里按手机实际像素再乘 `scale`）。`anchor` 是脚底中心。`display` 是屏幕上大约多大（画布会按它缩放）。**玩偶的大小以后还会调**（`sizeRange` 80–180 像素高），画法要在这个范围里都好看。

**视角**：俯视 3/4（看得到头顶）。噩梦从屏幕上方的雾里往下、朝窝里走；玩偶在窝里**走来走去**：往下走、站着没事时是**正面**（脸朝镜头），往上走、朝上面的噩梦出手时是**背面**（背朝镜头、能看到后脑勺和一点侧脸），横着走是**侧面**（画朝右）。不走动的玩偶只有正面，出手时身子朝上方一倾。

#### 3.2.1 每个朝向要哪些动作（2026-11-06 走位）

会走的（活动范围 中 / 大 / 冲：呼呼、方方、老袜、软软、阿冰）画三套，**噩梦都从上面来，所以出手只在背面和侧面**：

| 朝向 | 动作 |
|---|---|
| `front` 正面 | `idle`、`walk`（0.6 s 循环，原地踏步）、`cheer`、`startled`；**挡**另加 `knocked`（0.4 s 被挤倒，停在趴着的姿势）、`down`（1.6 s 循环，趴着晕乎乎）、`getup`（0.7 s 爬起来，回到 `idle` 第一帧） |
| `back` 背面 | `idle`、`walk`、`attack`（0.5 s）、`skill`（1.0 s）；**挡**另加 `block`（0.8 s 循环：身子前倾一下一下往前顶，噩梦那边播 `push`）；**冲**另加 `dash`（0.4 s 循环，肚皮着地往前滑）、`strike`（0.25 s 撞一下） |
| `side` 侧面（画朝右） | 同背面 |

不走的（不动：叮当、飘飘；小：嘎嘎、咔咔）只画 `front`：`idle`、`attack`、`skill`、`cheer`、`startled`，“小”的另加 `walk`（挪一两步）。出手时身子朝上方一倾。

- 三套是**同一个玩偶**：比例、颜色、部件的风格一致，转过去要认得出是它；背面能看到的东西（尾巴、背上的刺、发条钥匙、围巾结）要画出来，脸只露一点侧边。
- 每个有出手的朝向标一个**发射点** `muzzle`（嘴、手、天线……），`release` 那一刻弹道从这里出来。
- `walk` 原地踏步：脚和身子一颠一颠，**不要在动作里往前移**。

#### 3.6.1 月牙枕头窝（`obj_fort`，第 3 批；2026-11-06 改：不分格子）

- 以圆心（屏幕 375,1170）为中心，一道**月牙形的枕头墙**（半径约 360，开口朝屏幕底，一圈 6–9 个鼓鼓的枕头挨着）；墙里面是一整块**平的地**（被子、床单、小毯子铺开），玩偶在上面走来走去——**不画垫子、不分格子、地上不要有高出来的东西**。
- 圆心是糯糯的被窝（`kid_nuonuo` 另画、盖在上面），这里画一块枕头和被子的凹坑就行。
- 三档：1 = 几个枕头随手围了半圈（墙矮、缝大）；2 = 围成一整道墙；3 = 墙更高、被子更厚、多一条小花毯。三档的墙都在同一个位置。
- 墙往梦里那一面（上面）要有一点厚度和明暗，看得出噩梦是“挤过枕头墙”；漏怪时游戏让被挤的那一段凹一下（用 `fx_common` 的棉絮）。
- 地要**安静、中间调、几乎没有颗粒**（1.5 节第 5 条），玩偶站在上面要跳出来。

### 3.7 背景怎么画（三张都照这个）

- **750×1624，底对齐**：矮的手机（1334 高）会把**顶上 290** 裁掉，重要的东西别放在那里。
- 从上到下（括号里是 1334 高屏幕的坐标，画布坐标再加 290）：顶上一片**雾**，到屏幕 y≈262 渐淡（噩梦从雾的下沿出来，`fog` 色）→ 中间是**梦的地面**（y 262–774，噩梦往窝里走、弹道飞的地方，**平、静、中间调、几乎没有颗粒**，不要有抢眼的东西）→ 底下（y 774 起）是月牙窝 `obj_fort` 盖着，背景这里画床单 / 地毯就行。
- 这个梦的东西只放在**左右两边和顶上**：卧室——衣柜（门缝里透一点暗）、窗户和月光、玩具架；画得**暗、低对比**，不能比噩梦还显眼。左上角 y 170–220 是栅栏（在雾里，雾可以淡一点托住它），右边 (690, 830) 是手电按钮，这两处背景别放东西。
- 不放任何文字、不放刻板的文化道具；就是一个孩子的房间在梦里变大、变暗、有点歪。

## 7 自查（交之前逐条过）

- [ ] 只用 Canvas2D 标准接口（方案 3.3 第 1 条的禁用清单一条都没用）；不用 `Math.random`；不读外部图片、字体。
- [ ] 同一个 `seed` + `boil` 画两次，逐像素一样；换 `boil` 主要是笔触边和轮廓在变，造型不变。
- [ ] 预算：每个模块 gzip ≤ 12 KB、画笔库 ≤ 30 KB；L1 每个部件、L2 每帧画图调用 ≤ 3000；背景一次画完（Mac 上）≤ 300 ms。
- [ ] **颗粒（1.5 节）**：只在暗面和边缘；同色系深一档、没有统一的深蓝灰、没有亮点；脸、受光面、白毛受光面一颗都没有；灰度下亮度差 ≤ 6%、面积 ≤ 1/10；只一层；背景中间的地几乎没有；`setGrain(0)` 完全没有颗粒。
- [ ] **朝向**：三套是同一只（比例、颜色一致，转过去认得出）；侧面画朝右；`walk` 原地踏步、首尾无缝；每个有出手的朝向都有 `muzzle`，`release` 和 art-manifest 一样。
- [ ] **弹道**：只画飞的样子和打中，不画轨迹；直线的 `fly` 朝右；柱子、电光左右接得上；光环平放、半径对。

- [ ] `idle` 首尾无缝；动作播完回到 `idle` 第一帧；L1 部件绕关节转不露缝。
