## 0 一句话

窝里**不分格子**：玩偶拖到哪就守哪（守点），按自己的**活动范围**在守点附近自己走（挡迎上去拦、打走到够得着的地方打、帮不动放光环、冲跑出窝再回来）；上场**最多 6 只**；每次出手**转身 → 出手动作 → 弹道飞过去 → 到了才算伤害**；会走的玩偶有**正 / 背 / 侧**三套图。

## 1 数据（`levels.json` 第 2 版，`version: 2`）

| | 原来 | 现在 |
|---|---|---|
| `nest` | 12 个 `slots`（`arc`、`pos`、`adjacent`）、`openOrder`、`radius`、`spawn.lanes` / `edge`、`devices`（D1–D3） | `center`、`wall`（360）、`ground`（能站的地）、`squeeze`（1.2）、`dollSize`（120）、`homes`（默认守点）、`deviceHomes`、`spawn`（`y`、`x`、`speed` 56，**没有 lanes**）；`captain`、`kid`、`flashlight`、`fence`、`hud` 照旧 |
| `toys[]` | `stance`、`base`、`itv`、`aoe`… | 加 `range`（不动 / 小 / 中 / 大 / 冲）、`reach`（射程）、`windup`（出手到放出弹道的秒数）、`shot`（`kind`: straight / lob / beam / chain / melee + `speed` / `dur` / `arc`）、帮的 `aura`（光环半径） |
| `stance` | `block`、`startle: 2`、`dash`（`travel`）、`clone` | `block` 加 `meet`、`front`；`startle` 变 `{ sec, radius }`；`dash` 变 `{ cd, speed, back, hits, hitGap, hitMul, … }`；加 `range`（每档 `leash`、`speed`、`turn`）、`wander`、`gap`、`aura` |
| `slots` | `toy` 表、`device` 表、`rows`、`perRow` | 加 `toyCap`（6）；`rows` / `perRow` 只给核算用，游戏不读 |
| `econ` | `atk0` 4、`lvCapPerBoss` 70 | `atk0` 6、`lvCapPerBoss` 68（核算重新对齐了节奏，见 `docs/数值核算报告.md`） |

## 2 core

| 文件 | 原来 | 现在（开发文档节号） |
|---|---|---|
| `battle.ts` 场地 | 噩梦出生 x 分 5 段 → 走向外圈 O1–O5 的窝边点 | 直线朝圆心走，速度 `spawn.speed` 56；离圆心 ≤ `wall` 算到墙上（4.1） |
| `battle.ts` 漏怪 | 到窝边点：站“挡”→ 挡住；站别的 → 吓一跳 + 挤进；空 → 挤进 | 被“挡”挡住就停；到墙上没人挡 → 挤 `squeeze` 1.2 秒（还能打）→ 挤进窝掉层，挤进点 120 像素内的玩偶吓一跳 2 秒（4.2 第 5 条） |
| `battle.ts` 玩偶 | 站在固定位置，不动 | 每只有 `home`、`pos`；每步按打法算要去哪、按 `range` 的 `leash` / `speed` 走；没事时溜达；玩偶之间按 `gap × dollSize` 推开（4.6.1） |
| `battle.ts` 选目标 | 全场射程，打“最前面那只” | 射程 `reach` 以内离圆心最近的；射程里没有就往前挪（4.4、4.6.1） |
| `battle.ts` 挡 | 外圈的挡挡住走向它那个位置的噩梦 | 认领撞墙点在自己能去的地方的噩梦，迎上去站到它前面 `front` 44；离 `meet` 58 以内挡住；最多 2 只；耐力 / 挤倒照旧；不认领大噩梦（4.6.1） |
| `battle.ts` 冲 | 跑 1 秒过去、1 秒回原位 | `dash.speed` 560 冲过去（能出窝）、`dash.back` 300 跑回守点；目标优先级大噩梦 > 精英 > 离圆心最近（4.6.1） |
| `battle.ts` 辅助 | 加给 `adjacent` 的位置 | 加给光环 `aura`（175）以内的玩偶，按出手那一刻算（4.4） |
| `battle.ts` 出手 | 出手那一刻结算，弹道只是表现 | 出手 → 过 `windup` 放出弹道 → straight / lob **到了才结算**（目标中途没了：单体散掉、有范围的在最后位置炸）；beam / chain / melee 放出时结算（4.4） |
| `battle.ts` 大噩梦 | 走 40 秒到 O3 的窝边点 | 朝圆心走 40 秒到墙上；挡不住（4.10） |
| `battle.ts` 输入 | `{ flash }` | 加 `homes`（战斗中拖动换的守点）；新接口 `actors(b)` 给表现层读位置 / 状态 / 朝向用的速度和目标（6） |
| `battle.ts` 事件 | 出手（含伤害） | 拆成：出手（开始播动作）、弹道放出、打中（伤害）；加开始挡 / 挤倒 / 爬起来、冲出去 / 撞 / 跑回、吓一跳、挤墙（6） |
| `economy.ts` | `slotsOf` → 玩偶位、设施位；换位置 | `slotsOf` 加 `room`（枕头堡宽敞 = 表里的名额 ÷ toyCap，至少 1）；**全队倍数乘 room**，伤害分解加一行“枕头堡宽敞”；`place` / `placeDevice`（放上去、换守点、拿下来，守点夹进 `ground`，满了返回 null）（5.2、6） |
| `state.ts` / `Save` | `version: 1`，`lineup: (string\|null)[12]`，`devices: (string\|null)[3]` | `version: 2`，`lineup: { id, home }[]`，`devices: { id, home }[]`；读到 1 版自动迁移（9） |

## 3 表现

| | 原来 | 现在（开发文档节号） |
|---|---|---|
| 窝 | 12 个小圆垫 + 三道弧 | 一道月牙枕头墙 + 一整块地，没有垫子（7.1）；美术的 `obj_fort` 第 3 批才有，先用色块 |
| 换阵 | 点格子 → 选玩偶；点两个格子互换 | 面板卡片**拖进窝**上场（松手点 = 守点）；战场上**按住玩偶拖**换守点；拖出窝下场；设施同样（7.1） |
| 点玩偶 | 帮：画到挨着的位置的线 | 画守点（菱形）、活动范围（虚线圈，大 / 冲画整块地的边）、射程（细圈）、光环（绿圈）；面板写它在干什么（7.1） |
| 走 | 没有 | 播 `walk`（原地踏步）+ 位移；站住播 `idle`（7.2） |
| 朝向 | 没有 | 会转身的按速度 / 目标方向选 `front` / `back` / `side`（往左翻转）；不转身的只翻左右（7.2）。**没有美术的朝向用占位：背 = 压暗、侧 = 压窄**（同灰盒） |
| 出手 | 0.2 秒的弹道表现 | 出手动作播到 `release` 时，弹道从这个朝向的 `muzzle` 出来；直线的按方向转、抛物线边飞边转、柱子 / 电光两点之间拉伸；打中时播 `hit`、噩梦受击、跳数字（7.2）。弹道图来自 `shot_<玩偶>`，没有就用占位形状（灰盒里的样子） |
| 大小 | 玩偶约 96×104 | 玩偶高 `nest.dollSize`（120），按美术的 `display` 等比缩放（7.1） |
| `Rig.ts` | 一套部件 + 颗粒沸腾 | 加**朝向**：一个角色几套部件表和动作，按 7.2 切换；没有 `facings` 的老模块当作只有 `front`（7.2） |
| `ArtGen` | L1 名字 `<key>/<部件>#<boil>` | L1 名字 `<key>/<朝向>/<部件>#<boil>`，`opt.facing` 传给 `drawPart`；读模块的 `muzzle`、`release`；L3 弹道模块 `shot_*` 的 `fly` / `beam` / `bolt` / `aura` 笔刷和 `trail` / `hit` 配方（7.4，美术文档 2.1） |
| 调试面板 | 每个位置挨着谁、窝边点 | 全部玩偶的守点 / 范围 / 射程 / 光环、每只在干什么和朝向、弹道个数；一波一行加“第一次挨打时离墙还有几秒”（10） |

## 4 美术

- `美术/art-code/` 是**第 1 批返修**的定稿（用户认可了画风；颗粒偏多，第 2 批会改）：拷进 `assets/art-code/` 换掉 `_sample/`（`preview.html`、`交付说明.md` 不用进包）。它还是老接口（只有正面、`parts` 是数组），按“只有 front”接；呼呼的出手现在还是喷热气的身体动作，弹道先用占位火球（或拿 `fx_warm` 的笔刷拼一个，灰盒就是这么做的）。
- `_sample/` 里加一个**三套朝向**的 L1 样例和一个**弹道**样例（straight + lob 各一），照美术文档 2.1 的新接口，用来先把 ArtGen / Rig.ts 的朝向和弹道走通。
- 美术第 2 批（三套朝向的呼呼、方方、阿冰，正面的嘎嘎、叮当，5 个弹道，颗粒减量）正在画，交回后设计会给你，到时候换上再测。

## 5 测试（开发文档第 11 节，替换原来的 4、5、5b–5d）

- 4 名额和宽敞；5 光环只加罩住的；5b 走位（leash、往前挪、溜达、推开）；5c 挡（认领、迎上去、挡住、最多 2 只、挤倒、不认领大噩梦）；5d 漏怪（挤 1.2 秒、吓一跳范围）+ 冲；5e 弹道（到了才算、目标中途没了、windup、同种子同输入逐帧一样）；5f 存档迁移。

## 6 验收（开发文档第 13 节，改了的几条）

- 拖进 / 拖动 / 拖出玩偶和设施；点玩偶画出四种圈；名额 6 封顶后变宽敞，伤害分解里看得到。
- 五种活动范围走得对；挡迎上去挡住、挤倒、爬起来；没人挡的挤 1.2 秒进窝、旁边的吓一跳；冲出窝打完跑回守点；光环只加罩住的；大噩梦挡不住。
- 出手看得见：转身、出手动作、弹道从发射点飞到目标、打中特效 + 受击 + 数字同时出现；九只的弹道种类各是各的；正 / 背 / 侧切换对（没美术用压暗 / 压窄）。
- 旧存档读进来自动迁移；1334 / 1624 两种高度玩法一样。
- 截图对比：和 `docs/布局方案/走位灰盒.png` 放在一起，大小、走位、弹道的感觉差不多。
