# 《枕头堡》P1 规则缺口与可调整选择

## 使用说明

本清单审阅开发包第二版。已有明确规则继续实现，不为缺少美术或外部工具停工。原始 `levels.json`、`art-manifest.json` 与 `docs/spec/` 保持不变。以下“建议”是保守、可撤换的实施选择，并非设计方已确认的新增规则；最终交付须记明实际采纳哪一项。

## 规格中已经明确，可直接消除旧文案歧义

1. 辅助按 `nest.slots[].adjacent`，不是同排。JSON `toys[].desc` 中旧“同一排”、`slots.rows/perRow` 不控制新版玩法。
2. 初始开放按 `nest.openOrder` 前3项，即O3、M2、M3。存档lineup仍按slots数组顺序存，不能使用openOrder数组顺序做存档索引。
3. 第一区到第三区用 `phase ≤ 1` 的目标实体。`unlocks` 自身没有phase，必须过滤每个引用ID；不能让P2研究/宝贝混进解锁卡。
4. `nightmares.notebook.hp = 0.4` 已表示成群每只40%，不要另乘0.4。迟到闹钟speed=1.4已表示快，也不要另乘1.4。
5. 玩偶 `aoe`、`flash.manualBoss/autoBoss`、`stance.dash.bossMul/waveMul` 是核算侧参数或未获正文采用的参数。实际战斗按正文命中和范围，不另外乘一层所谓估算增益。
6. `story.phase=3` 不应使P1要求的 `story.kidName` 和两句开场不可用；P1不展示后续剧情系统即可。
7. 阿冰在第二区首领胜利时才解锁。P1三梦结束后仍需有现区试玩/挂机或调试验证路径，否则正式游玩几乎看不到“冲”。不得擅自提前解锁阿冰来掩盖这个阶段设计。
8. 通用规范的“12关/首页选关/撤回重来”是其他demo的旧通用文字，不用于这款放置塔防。以本游戏0–2区、49普通波+首领为准。

## 仍缺少的外部输入与验收影响

1. `10-big-number-rules.md` 第5.5节完整对照表不在开发包中。现有包只能支持文字规则与自建边界用例。
2. `calc/core.mjs`、`calc/README.md`、content/export源码未打包。已有数值核算报告包含P2/P3的研究、宝贝、广告、摇篮曲等。不能要求P1精确复现报告1.5天通第三首领或平均263级的结果。
3. `shadehome-mini`框架与共享build-kit、其他项目NOTES未在开发包中。新写等价框架/构建脚本应声明，不得声称复用了未读取的文件。
4. 正式美术与本轮色块占位范围不同。可预留ArtGen接口，但仅存在接口/样例不等于正式6件美术双平台验证通过。
5. Cocos编辑器、微信开发者工具、iPhone与安卓真机测试不能由纯Node/TypeScript通过替代。记录“未运行”，列出用户最小本地验证步骤。
